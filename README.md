# LAS Feature Extraction Tools
    
    A toolkit for clipping specific features from LAS point clouds using geometry extracted from ArcGIS Pro.
    
    ## Overview
    
    This workflow consists of two parts:
    1. **Preprocess_Tool.py**: An ArcGIS Pro script tool that prepares 3D extract masks (buffered polygons with Z-values) from simple point/line inputs.
    2. **Extract_LAS.py**: A high-performance standalone Python script that uses the masks to clip corresponding LAS data.
    
    ## 1. Preprocess Tool (ArcGIS Pro)
    
    ### Input Schema
    The tool expects a Point layer (and optional Line layer) with the following fields:
    
    | Field | Type | Description |
    |---|---|---|
    | `ID` | String/Int | Unique identifier for the feature. |
    | `Type` | Text | Determines the buffer size (e.g., "Manhole", "Valve"). |
    | `Height_txt` | Text/Double | The height of the object (used for Z-extrusion). |
    | `Span_txt` | Text/Double | (Optional) Manual buffer override for generic types. |
    
    ### Configuration
    The mapping between feature `Type` and buffer size is defined in the `TYPE_CONFIG` dictionary at the top of the script.
    
    ## 2. Extract LAS (Standalone)
    
    A memory-efficient script that clips LAS files using the geometries generated by the Preprocess tool.
    
    ### Features
    - **Memory Safe**: Processes LAS files one by one to prevent RAM overflow.
    - **Fast**: Uses Shapely 2.0+ vectorized operations and WKB geometry parsing.
    - **Folder Organization**: automatically sorts clipped LAS files into folders by `Type`.
    
    ### Usage
    Update the paths in the `__main__` block or modify to accept command line arguments:
    ```python
    process_las_extraction(
        gdb_path=r"C:\Project\MyProject.gdb",
        feature_dataset="LAS_Masks",
        las_folder=r"C:\Data\LAS",
        output_folder=r"C:\Output\Clipped"
    )
    ```
    
    ### Dependencies
    Install requirements via pip:
    ```bash
    pip install -r requirements.txt
    ```
